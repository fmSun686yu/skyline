# 仓库修改与优化方案

本目录用于集中保存 Skyline **整个仓库**的修改与优化方案，包括配置模板、文档、软件功能、构建及发布流程等。

## 使用约定

1. 后续修改与优化的方案统一保存在本目录，不分散放入各功能目录。
2. 文件名采用 `YYYY-MM-DD-主题-vN.md`，使用简短的英文主题和明确的方案版本号。
3. 每份方案应包含背景、范围、逐项修改内容、行为影响、验证方法、验收标准及实施状态。
4. 方案版本与模板或软件版本独立：例如方案 v4 不表示模板应升级为 v4。
5. 方案发生实质性调整时保存新版本，更新本索引；保留已有版本，便于追踪决策。
6. 方案确认、文件实施、静态校验、实际环境验证分别记录。保存方案不代表已经实施或验证通过。
7. 不在方案中记录真实订阅链接、密码、控制密钥或其他私人凭据。地址和账号示例应明确标注用途。
8. 使用方案内的稳定编号讨论和核对修改范围；实施前重新读取目标文件，保留用户已有修改。
