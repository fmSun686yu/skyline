## 用户审核方式

1. 完整解压 ZIP，双击 `Skyline.exe`。
2. 确认英文窗口显示 `0.1.0-s01` 和 `S01 / FOUNDATION PREVIEW`。
3. 确认显示 `Built-in templates verified`、Windows desktop `v1.2.3` 和 NAS `v2.1.2`。
4. 审阅源码、模板清单及本报告。确认 S01 后再开始 S02 配置生成核心。
